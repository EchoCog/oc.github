# OpenCog Hyperon

Being developed by [Singularity.net](https://singularitynet.io).

## About Hyperon

Hyperon represents the next generation of the OpenCog framework, designed and developed by SingularityNET. It builds upon the foundational concepts of the AtomSpace while introducing new paradigms for AGI development.

## External Links

- [SingularityNET](https://singularitynet.io)
- [Hyperon Documentation](https://wiki.opencog.org/w/Hyperon)

## Development

```bash
# Install dependencies
npm install

# Build
npm run build

# Test
npm run test

# Development mode
npm run dev
```

## Integration

This workspace serves as a bridge between the traditional OpenCog AtomSpace and the new Hyperon framework, facilitating:

- Migration paths from AtomSpace to Hyperon
- Compatibility layers and translation tools
- Shared research and development resources
- Community collaboration between projects
