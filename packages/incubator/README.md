# OpenCog Incubator

Experimental and proof-of-concept projects under development.

## Incubator Components

* **as-moses** - Port of MOSES to the AtomSpace
* **Vision** - Extracting structure from images, video (proof-of-concept)
* **Hyperon-on-top-of-atomspace** - Hyperon backwards-compat layer (proof-of-concept)
* **SpaceTime** - Octree spatial bounding boxes and time intervals in Atomese

```bash
# Test
npm run test

# Development mode
npm run dev
```

## Project Status

These are experimental projects that may graduate to the main OpenCog ecosystem or serve as research prototypes. They represent cutting-edge work in:

- Evolutionary algorithms integration
- Computer vision and image processing
- Hyperon compatibility layers
- Spatial-temporal reasoning systems
