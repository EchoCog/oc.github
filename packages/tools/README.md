# OpenCog Tools

Development utilities and helper tools for the OpenCog ecosystem.

## Tools Collection

This workspace contains various utilities and tools to support OpenCog development:

- Build and deployment scripts
- Testing utilities
- Code generation tools
- Development environment setup
- Continuous integration helpers
- Documentation generators

## Development

```bash
# Install dependencies
npm install

# Build
npm run build

# Test
npm run test

# Development mode
npm run dev
```

## Usage

Tools in this workspace are designed to support development across all other OpenCog workspaces. They provide:

- Cross-workspace build coordination
- Shared testing infrastructure
- Common development workflows
- Integration testing tools
